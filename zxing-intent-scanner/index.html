The problem

Your app needs scanning, but you may not want to build a scanner from scratch

Some Android workflows only need a reliable way to launch a scanner, capture a barcode or QR code and return the value to the original app. Rebuilding camera handling, recognition and result delivery can add unnecessary complexity when an external scanner already fits the workflow.

Keep the integration code simple

The exact Intent action, extras and result keys must match the interface supported by the installed Nemo version. Use the structure below as an integration pattern, then replace the placeholder values with Nemo's published contract. 

Intent intent = new Intent("YOUR_SUPPORTED_SCAN_ACTION");

// Optional examples — use only values supported by Nemo.
// intent.putExtra("SCAN_MODE", "QR_CODE_MODE");

startActivityForResult(intent, REQUEST_SCAN);
@Override
protected void onActivityResult(
        int requestCode,
        int resultCode,
        Intent data
) {
    super.onActivityResult(requestCode, resultCode, data);

    if (requestCode == REQUEST_SCAN && resultCode == RESULT_OK) {
        // Replace this key with Nemo's documented result key.
        String result = data.getStringExtra("YOUR_RESULT_KEY");

        // Use the scanned value in your app.
    }
}
Do not copy placeholder action names or result keys into production. Publish only the exact Intent contract that the current Nemo app actually supports.
